**Sorteador de Números Aleatórios**

**Descrição**

Projeto desenvolvido com Arduino Uno, utilizando um display de 7 segmentos e um botão para realizar sorteios de números aleatórios de 0 a 9.

Ao pressionar o botão, o display começa a apresentar números rapidamente. Ao pressioná-lo novamente, o sorteio é interrompido e o último número exibido permanece na tela.

**Componentes**

- Arduino Uno
- Display de 7 segmentos (cátodo comum)
- Botão push button
- Resistor
- Protoboard e jumpers

**Descrição técnica**

O sistema utiliza as portas digitais do Arduino para controlar os segmentos do display e realizar a geração de números aleatórios através da função random().
O botão conectado ao pino digital 9 controla o início e a interrupção do sorteio.
